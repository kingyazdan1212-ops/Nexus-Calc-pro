## ویژگی‌ها

- 🎨 **طراحی روشن و خیره‌کننده** با تم تیره هم
- 🧮 **دو حالت**: پایه + علمی کامل
- 📜 **تاریخچه محاسبات** (ذخیره در مرورگر)
- ⌨️ **پشتیبانی کامل از کیبورد**
- 📱 **کاملاً ریسپانسیو** و آماده PWA
- ✨ انیمیشن‌های نرم و حرفه‌ای
- 🌐 آماده انتشار روی GitHub Pages

## نحوه استفاده

1. فایل‌ها را در یک ریپازیتوری GitHub آپلود کنید
2. در Settings → Pages، Source را روی `main` branch بگذارید
3. سایت شما آماده است!

یا برای تبدیل به اپ:
- از **PWA Builder** یا **Capacitor** استفاده کنید
- یا مستقیماً از مرورگر «Add to Home Screen» بزنید
